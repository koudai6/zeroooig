字卡聊天更新版部署说明

1. 将本压缩包内文件上传到 GitHub Pages 网站根目录，覆盖原 index.html、sw.js、font.woff。
2. 语音录制需 HTTPS 并允许麦克风权限。自动转文字依赖浏览器 SpeechRecognition 支持；若浏览器不支持，仍可发送语音，但不会显示转写文字。
3. 新设置位于「设置」->「字卡回复」：拼字卡最少/最多句数、拼字卡概率、已读不回概率。
4. 空输入框点击发送键会触发对方主动发送消息。
5. 转账/传信入口已从主界面移除；原有聊天记录、字卡库、朋友圈、抉择、装扮、备份等功能保留。
6. 按最新要求，网站每次重新打开/刷新都会清空本地存档并从空白状态启动（联系人、聊天记录、字卡、朋友圈、设置等不会跨次保留）。如需保留数据，请不要使用此版本。
7. 输入框提示已恢复为「输入消息」；长按录音时显示红色波形动画。录音使用独立音频缓存，并限制单个播放器播放，减少语音重复/串音问题。
